# 게시판 기능 상태

## 1. 현재 /lost-pets 상태

- `/lost-pets`에는 보호동물 공고 탭과 실종 제보 탭이 있다.
- 보호동물 공고는 공공데이터 snapshot 기반으로 표시한다.
- 실종 제보 탭은 내부 DB에 저장된 승인/찾음 상태 제보를 보여준다.
- `/lost-pets/new`에는 실종 제보 등록 폼이 있다.
- `/lost-pets/[id]`에는 상세 화면과 목격 제보 입력 흐름이 있다.
- 사용자 실종 제보의 수정/삭제, 계정 기반 본인 관리, 운영자 승인 화면은 아직 충분하지 않다.

## 2. 앞으로 필요한 실종 제보 게시판 기능

- 실종 제보 글쓰기 개선
- 사진 업로드
- 위치 선택
- 사례금 입력
- 연락처 보호
- 댓글/목격 제보
- 상태 변경: 실종/목격/보호/완료
- 관리자 승인
- 신고/차단
- 허위 제보 방지

## 3. 업체 정보 수정 제보 게시판

- 주소 오류 제보
- 전화번호 오류 제보
- 폐업 제보
- 반려동물 동반 조건 수정 제보
- 대표 메뉴/서비스 제보
- 사진 제보
- 관리자 확인 후 공개 반영
- 반복 허위 제보 제한

## 4. 방문 리뷰와 게시판 구분

- 리뷰는 실제 방문 경험 평가를 다룬다.
- 정보 수정 제보는 전화번호, 주소, 폐업, 동반 조건, 대표 서비스/메뉴 보강을 다룬다.
- 실종/목격/보호 제보는 `/lost-pets` 게시판 성격의 신고 흐름으로 분리한다.
- 외부 리뷰, 블로그, 카페 본문은 크롤링하거나 저장하지 않는다.
- 운영 초기에는 공개 게시판보다 리뷰, 제보, 관리자 확인 흐름을 우선한다.
