# Lost Pets Board Status

## 현재 /lost-pets 상태

- `/lost-pets`는 보호동물 공고 탭과 실종 제보 탭을 제공한다.
- 기본 진입은 보호동물 공고 탭이며, `/lost-pets?tab=pets`에서 실종 제보 목록을 보여준다.
- 보호동물 공고는 공공데이터 기반 snapshot을 읽어 표시한다.
- 실종 제보는 내부 DB에 저장된 승인/찾음 상태의 항목을 목록으로 보여준다.
- `/lost-pets/new`에는 실종 제보 등록 폼이 있고, 제출 후 내부 검수 상태로 저장된다.
- `/lost-pets/[id]`에는 상세 화면과 목격 제보 입력 폼이 있다.

## 아직 없는 사용자 게시판 CRUD

- 일반 사용자가 본인 글을 수정하거나 삭제하는 흐름은 없다.
- 사진 파일 업로드는 없고, 현재는 사진 URL 입력만 가능하다.
- 지도 기반 위치 선택은 없다.
- 사용자 계정, 작성자 인증, 본인 확인 기반 관리 기능은 없다.
- 관리자 승인/상태 변경 전용 운영 화면은 아직 게시판 기능으로 정리되어 있지 않다.

## 필요한 기능 목록

- 글쓰기
- 사진 업로드
- 위치 선택
- 사례금
- 연락처 보호
- 댓글/제보
- 상태 변경
- 관리자 승인
- 신고/차단
